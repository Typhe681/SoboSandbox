# SoboSandbox!
Unlocks gamemodes and adds a sandbox gamemode that:
- unlocks developer hotkeys
- prevents gameover
- locks achievements + scores

Tested on Sobosuba v1.2.3 (Godot 4.7.2)


## How to install:
Install GDPatch (https://gdpatch.dev/using/install/)

Run the game once to setup GDPatch

Extract sobosandbox.zip into sobosuba\GDPatch\mods\sobosandbox

That's it :3


## How to uninstall:
Question why you would do this

Just delete the mod folder and GDPatch's files


## Hotkeys:
| Key | Description |
| --- | --- |
| S | Spawn sobo¹ |
| Shift + S | Fill board with sobos |
| X | Delete sobo |
| Shift + X | Delete all sobos |
| D | Drag sobo |
| V | Toggle debug sobo rendering |
| Q / E | Press bumpers in |
| C | Shockwave |
| L | Cycle language |
| Numpad+ | Save game |
| Numpad- | Load game |
| Numpad* | Clear save |

¹collision check can be disabled in settings with the 'unrestricted spawn' toggle
